Active Users Dropout Classification Algorithm

Priority cascade: ① Active Range (Weeks) → ② Message Number → ③ Word Length → ④ Classify

Status Definitions

Transient — lurker, reaction-only, or insufficient weekly / message presence
Dropout — was genuinely engaged, then went silent (tiered: recent / faded / gone)
Cooling — sustained baseline, but recent 4-week activity fell ≥ 40% vs prior 4 weeks
Active — passes all gates, sustained over the window, not silent or cooling

✦ Adaptive compensation: excelling in a higher-priority dimension relaxes the bar in the next dimension — it does not skip it. Gates 1–3 can each be lowered but never waived.

✦ weekBonus (≤ 20%): earned when pctWeeks exceeds activePctWeeks. Reduces ② message thresholds. Max relaxation: 25% of base (floor at 75%).

✦ msgBonus (≤ 30%): earned when total_messages exceeds activeMinMessages. Reduces ③ word-length threshold. Floor is always 2 avg words (excludes "+1" reactions regardless).

✦ Dual-signal silence: a user is "dropout-silent" when both conditions hold: (a) silenceDays ≥ 14 d, and (b) relSilence ≥ 55% of own active span or absFrac ≥ 28% of the full window. Veterans get proportionally more tolerance before being called a dropout.

✦ Window scaling: all thresholds scale with windowDays. A 56-week window requires ~168 messages for Active vs ~21 for a 7-week window. pctWeeks bars also rise (e.g. activePctWeeks goes from 25% → 40% for a year-long window).
